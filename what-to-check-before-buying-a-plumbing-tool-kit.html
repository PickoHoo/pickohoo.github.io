Buying a plumbing tool kit? Five checks before you choose

A practical pre-purchase checklist, not a hands-on review. We have not tested these tools. These are buyer questions, not verified specifications of this product.

  1. Check the actual kit contents

    Make a list of the tools you already own and check the retailer's full included-item list for gaps. A piece count does not tell you which tools are included.

  2. Match the kit to the work

    Write down the kinds of plumbing jobs you intend to do. Check whether the manufacturer's supplied components actually suit them.

  3. Check size and storage

    Consider whether the case fits your van, workshop or available storage, and check the full product dimensions with the retailer.

  4. Check the total delivered price

    Check current VAT-inclusive price, shipping costs, stock and dispatch estimate in the retailer's checkout before buying.

  5. Check guarantees and returns

    Read the retailer's latest returns conditions, any applicable warranty terms, and the maker's product documentation.
